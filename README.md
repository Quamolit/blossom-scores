
Blossom Scores
------

Demo http://repo.quamolit.org/blossom-scores/

A tiny MVC game exercise based on HTML5 canvas.

* track spots to increase your score
* press Space to restart
* you have only 30 seconds in each race

The Calcit 0.18.1 migration currently pins Quamolit `0.0.18-alpha.1` and uses
a compile-only bootstrap entry. CI verifies compilation, not gameplay; the
original app entry still needs strict-type migration.
